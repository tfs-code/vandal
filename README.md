# Vandal

Vandal is a Valorant rank tracker powered by HenrikDev's unofficial Valorant API.

## Overview

Track and view Valorant rank information in one place. Vandal retrieves player data through the [HenrikDev Valorant API](https://github.com/Henrik-3/unofficial-valorant-api).

## Features

- Look up Valorant player ranks
- View current competitive rank information
- Use HenrikDev's unofficial Valorant API as the data source
